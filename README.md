# kNN on Fashion-MNIST

k-Nearest Neighbors classification baseline on the [Fashion-MNIST](https://github.com/zalandoresearch/fashion-mnist) dataset, submitted as Homework 1 for CS412 (Machine Learning).

The notebook walks through:

- Loading Fashion-MNIST via `sklearn` / `tensorflow`
- Train/test split and basic visualization
- kNN classification with multiple `k` values
- Confusion matrix and per-class accuracy
- Discussion of trade-offs (compute vs accuracy, distance metrics)
